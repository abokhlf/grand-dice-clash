# لعبة لودو أونلاين — فخامة عربية تراثية

لعبة لودو كاملة بواجهة عربية (RTL) بطابع تراثي فاخر: فيروزي عميق، عنابي، وذهبي، مع زخارف إسلامية هندسية. لعب أونلاين حقيقي بين 2-4 لاعبين، مع أصوات، إحصائيات، عملات وتخصيص، ودردشة إيموجي.

## الشاشات

1. **الرئيسية** — لوحة اللعبة كخلفية متحركة، أزرار: لعب سريع، إنشاء غرفة، انضمام بكود، ضد الكمبيوتر، المتجر، الملف الشخصي.
2. **تسجيل الدخول** — بريد/كلمة مرور + اسم لاعب وصورة رمزية.
3. **الردهة (Lobby)** — كود الغرفة، مقاعد اللاعبين، اختيار اللون، جاهزية، بدء المباراة.
4. **طاولة اللعب** — لوح لودو 15×15، نرد ثلاثي الأبعاد بالحركة، تمييز الحركات الممكنة، مؤقت للدور، شريط دردشة وإيموجي سريع.
5. **النتيجة** — الترتيب، العملات المكتسبة، الإنجازات المفتوحة، إعادة اللعب.
6. **المتجر والتخصيص** — أطقم قطع، ألواح، أنماط نرد، إطارات صور — تُفتح بالعملات.
7. **الملف الشخصي** — إحصائيات (مباريات، فوز، نسبة الفوز، أطول سلسلة)، شارات الإنجازات، لوحة المتصدرين.

## قواعد اللعبة

- 4 قطع لكل لاعب، خروج القطعة بـ 6، دور إضافي عند 6 أو أكل قطعة أو إدخال قطعة للبيت.
- ثلاث ستات متتالية تُلغي الدور، خانات آمنة معلّمة بالنجمة، أكل قطعة الخصم يعيدها للقاعدة.
- الفوز بإيصال القطع الأربع للمركز؛ الترتيب يستمر لبقية اللاعبين.
- منطق الحركة يُنفّذ على الخادم لمنع الغش؛ رمي النرد يتم بمولّد عشوائي على الخادم.

## الأونلاين

- تفعيل Lovable Cloud للحسابات وقاعدة البيانات والتزامن الفوري.
- جداول: الملفات الشخصية، الغرف، اللاعبون في الغرفة، حالة المباراة، الحركات، الرسائل، العناصر، مقتنيات اللاعب، الإنجازات.
- تحديث فوري للوحة والدردشة عبر الاشتراك المباشر (Realtime) — كل الأجهزة ترى نفس الحالة لحظياً.
- إعادة الاتصال التلقائي واستئناف المباراة، ولعب تلقائي عند انتهاء مؤقت الدور.

## الأصوات والحركة

- مؤثرات: رمي النرد، تحرك القطعة، الأكل، الفوز، ونقرة الأزرار + موسيقى خلفية هادئة بطابع شرقي مع زر كتم.
- حركات سلسة: قفز القطعة خانة بخانة، توهج ذهبي للدور الحالي، احتفال جسيمات عند الفوز.

## التنفيذ التقني

- TanStack Start + React + Tailwind، اتجاه RTL وخط عربي معبّر (عناوين زخرفية + متن واضح).
- نظام تصميم بالكامل بـ tokens في `src/styles.css`: `--background` فيروزي داكن، `--primary` ذهبي، `--accent` عنابي، تدرجات وظلال ذهبية.
- لوح اللعب مرسوم بـ SVG/CSS grid قابل للتوسع، مع مسارات إحداثيات مشتركة بين العميل والخادم.
- منطق اللعبة في وحدة مشتركة نقية + دوال خادم (`createServerFn`) للتحقق والتطبيق، وسياسات أمان على مستوى الصف لكل الجداول.
- المرحلة الأولى: الحساب + الغرف + اللوح ومنطق اللعب الكامل + الدردشة. المرحلة الثانية: المتجر والإنجازات ولوحة المتصدرين + وضع الكمبيوتر.
